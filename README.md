# scp-social-assets

Repositorio publico solo para alojar las imagenes generadas por el pipeline de contenido de SCP Gym Tracker (posters de LinkedIn/Instagram).

Existe porque el repo principal de la app (sobrecarga) es privado y Buffer exige una URL publica para las imagenes de cada post. No contiene codigo, solo imagenes subidas automaticamente por `scripts/publish-draft-to-buffer.js` en el repo `sobrecarga`.
